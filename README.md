# Prototype Fund Brand Design
In this repository, you can find all the assets, logos etc. we use for communicating around the Prototype Fund. 

### Typeface 
We use two typefaces across all our communications:  
**[Surt](https://blazetype.eu/typefaces/surt/)** is the primary typeface, used for headlines and key messaging.  
**[Inclusive Sans](https://github.com/LivKing/Inclusive-Sans)** is the secondary typeface, used for body copy and supporting text. It comes in a wide range of weights to provide flexibility across different applications, and aid readability.
